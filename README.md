# Task Manager

Prosta aplikacja do zarządzania zadaniami w React + TypeScript.

## Funkcje

- dodawanie nowych zadań
- edycja istniejących zadań
- oznaczanie jako wykonane / niewykonane
- usuwanie z potwierdzeniem
- wyszukiwanie po tytule i opisie
- filtrowanie zadań: wszystkie, aktywne, ukończone
- zapis stanu w `localStorage`

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS

## Uruchomienie

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod adresem `http://localhost:5173`.

## Build

```bash
npm run build
```
